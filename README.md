# Монитор охраны труда

Статический сайт с ежедневным дайджестом изменений законодательства РФ об охране труда по официальным источникам (pravo.gov.ru, regulation.gov.ru, Госдума, Минтруд, Роструд, Онлайнинспекция.рф, ВС РФ, Ростехнадзор, Минздрав и др.).

## Как устроено

| Файл | Что это |
|---|---|
| `index.html` | Страница ленты: фильтры по периоду, типу документа, теме и источнику, поиск. Читает `data/*.json`. |
| `data/updates.json` | Все записи ленты (массив объектов, новые сверху). |
| `data/runs.json` | Журнал ежедневных сборов: дата, окно, сколько добавлено, что проверено, что не открылось. |
| `feed.xml` | RSS-лента, собирается из `updates.json` скриптом. |
| `scripts/build_feed.py` | Генератор `feed.xml`. |

Обновляет данные запланированная задача в Claude: каждый будний день утром она ищет новые документы, дописывает их в `data/updates.json`, добавляет запись в `data/runs.json`, пересобирает `feed.xml` и делает коммит в ветку `main`. GitHub Pages публикует изменения автоматически в течение пары минут.

## Публикация на GitHub Pages

1. Создайте репозиторий (например `ot-monitor`) и загрузите в него содержимое этой папки.
2. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://<аккаунт>.github.io/ot-monitor/`.
4. Свой домен: Settings → Pages → Custom domain (нужна CNAME-запись у регистратора).

## Формат записи в `data/updates.json`

```json
{
  "id": "2026-09-11-prikaz-345n-sout-malye-predpriyatiya",
  "date": "2026-09-11",
  "source": "pravo.gov.ru",
  "kind": "act",
  "title": "Приказ Минтруда России от 07.08.2026 № 345н «…»",
  "summary": "2–4 предложения: что меняется, кого касается, когда вступает в силу.",
  "url": "https://…",
  "topics": ["СОУТ", "вредные условия"],
  "effective": "2027-03-01",
  "addedAt": "2026-09-28"
}
```

`kind`: `act` — принятый акт, `draft` — проект НПА или законопроект, `letter` — письмо/разъяснение, `court` — судебная практика, `event` — официальное мероприятие.

`topics`: СОУТ, СИЗ, обучение, медосмотры, несчастные случаи, правила по ОТ, проверки, ТК РФ, гарантии и компенсации, вредные условия, прочее.

## Пересобрать RSS вручную

```bash
python3 scripts/build_feed.py --base https://alimovdamir.github.io/ot-monitor/
```
